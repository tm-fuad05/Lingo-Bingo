# Lingo Bingo: A Vocabulary Learning Application

Lingo Bingo is an interactive web application designed to help users expand their vocabulary and improve their language skills. It offers a dynamic and fun way for users to learn vocabulary in multiple languages (excluding Bengali and English), making the process of learning new words easier and more enjoyable.

---

## 🚀 **Live URL**

**https://lingo-bingo-eb946.web.app/** 

---

## 🔑 **Key Features**

- **Multi-Language Support**: Users can choose from various languages (e.g., Spanish, Japanese, etc.) to learn vocabulary.
- **Secure Authentication**: Firebase authentication using Google OAuth for easy login and registration.
- **Interactive Vocabulary Lessons**: Users can view vocabulary lessons with words, meanings, pronunciations, and usage examples.
- **Difficulty-Based Categorization**: Words are grouped by difficulty levels (easy, medium, and difficult).
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices.
- **Profile Management**: Users can manage their profile information, including their name and photo.
- **YouTube Tutorials**: Embedded language tutorial videos to enhance learning.
- **Voice Pronunciation**: Click on vocabulary cards to hear the word’s pronunciation.
- **Animations**: AOS (Animate on Scroll) library to add smooth animations on the page.
- **Error Handling**: Custom 404 error page with a "Back to Home" button if an invalid route is accessed.

---

## 🛠 **Technologies Used**

- **Frontend**: React.js, React Router DOM
- **Backend**: Firebase (for user authentication and Firestore storage)
- **Other Packages**:
  - `firebase`: For user authentication and Firestore database management.
  - `react-router-dom`: For routing and navigation between pages.
  - `react-toastify`: For displaying notifications and alerts.
  - `aos`: For adding smooth scroll animations on the website.
  - `react-icons`: For using scalable vector icons in the UI.
  - `react-countup`: To animate numerical values such as user count and vocabulary count.
